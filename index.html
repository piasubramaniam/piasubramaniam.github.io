That lets me turn stakeholder needs into products engineers can build and users understand. I also work with AI as a companion, not just a chatbot: I write skills and instructions for AI agents such as Claude Code and orchestrate them to build and test my code.

Planning & delivery of a Java reading app

Search & navigation concept (CLI mockup)

1 / 4

In a Scrum team, planning and building a Java app that lets learners load, search and navigate long texts instead of scrolling raw text files.

  • Mapped stakeholders by interest and influence and prioritised scope with MoSCoW
  • Broke the work into a WBS, Gantt plan and critical path across six one-week sprints
